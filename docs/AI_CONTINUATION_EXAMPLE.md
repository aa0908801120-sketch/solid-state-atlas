# AI 延續專案示範：規則如何幫助繼續開發

## 情境
未來想在「元件與接面」增加「蕭特基接觸與歐姆接觸」主題，AI 應先讀根目錄 `AGENTS.md` 和 `README.md`，理解檔案結構與驗收流程，不要另外建立彼此不一致的 HTML。

## 可以直接交給 AI 的提示詞
> 請先閱讀本專案的 AGENTS.md 與 README.md，依照完整物件欄位在 `data/notes.js` 新增一篇「蕭特基接觸與歐姆接觸」繁體中文筆記，使用唯一 slug `schottky-contact`。至少三個核心觀念、一個含適用條件的公式或關係、一段常見迷思，以及一題有解析的自我檢核。請不要更動無關的 HTML / CSS 或現有筆記。新增後執行 `python3 tests/check_site.py` 並檢查首頁搜尋、分類、詳情網址、收藏、已讀、明暗模式、行動版。最後列出修改檔案、測試結果與人工需確認事項。

## 預期驗收
- 首頁筆記總數由 9 增加為 10。
- 搜尋「蕭特基」及選擇「元件與接面」能找到新筆記。
- `#/note/schottky-contact` 可直接開啟，內容的概念、公式、迷思、自我檢核正確顯示。
- 原有收藏、已讀、明暗模式與響應式版面不受影響。
- Python/Node.js 檢查全部通過，發布後 GitHub Pages 正常讀取。

## 為什麼能讓 AI 延續？
`AGENTS.md` 指定資料唯一來源、欄位格式、文字風格、科學正確性原則與測試步驟。AI 可只修改 `data/notes.js`，由 `assets/app.js` 自動顯示筆記卡片及文章；開發完成還有可重複檢查的標準，降低不同 AI 多次修改所造成的風格漂移與功能退化。
